## 1. プロジェクト概要

### 1-1. 基本情報

| 項目 | 内容 |
|---|---|
| サービス名 | Cautas（カウタス） |
| 種別 | カウンセラー向け業務管理アプリの紹介サイト |
| URL（現行アプリ） | https://cautas.pages.dev/ |
| 構成 | Front（体験型LP）+ Guide（説明書・ヘルプセンター） |

### 1-2. 目的

- 見た人に「使いたい」と思わせる
- 体験を通じてCautasの価値を直感的に伝える
- CTAへ誘導し、無料トライアルへ繋げる

### 1-3. 作り手の想い

- AIにコード任せではなく、自分で設計・実装を理解したい
- デザイン・アニメーション・世界観を自分のイメージ通りに作りたい
- 大きく印象的な動き（1動作1意味）を好む
- 細かい連続アニメーションは避けたい
- 学習しながら進めるため時間がかかることは許容

## 2. ターゲット

### 2-1. メインターゲット

- カウンセラー（独立・小規模）
- セラピスト
- 心理士

### 2-2. ターゲットの特徴

- 人と向き合う仕事 → 人間味・温かみ重視
- 事務作業が苦手 → 「これで楽になる」に反応
- 信頼・誠実さ重視 → 派手すぎはNG
- ITリテラシーは高くない可能性 → 複雑さは離脱要因

### 2-3. ターゲットの困りごと

- セッション後の記録・報告書作成が負担
- 何を書けば良いか迷う
- 実績管理が後付きで面倒
- 請求漏れが発生する
- 過去のクライアント情報を探すのに時間がかかる

## 3. 価値提案

### 3-1. キャッチコピー

| 種類 | コピー |
|---|---|
| メイン | 「予定を入れるだけ。あとは全部、繋がる。」 |
| サブ | カウンセラー向け業務管理アプリ（予約・カルテ・実績・請求を一元管理） |
| 感情ゴール | 「クライアントに集中できる毎日へ」 |

### 3-2. Cautasの機能

- 予約管理（場所・URL・電話番号の自動紐付け）
- クライアント情報管理
- タスク作成（予定に対するタスクをスケジュール化）
- 音声認識でセッション記録
- AI分析（セッション振り返り）
- 報告書作成（AI下書き）※未実装・予定
- 実績自動カウント
- 請求書作成
- 未請求・請求済み管理

### 3-3. Cautasあり/なし比較（カウンセラーの場合）

| タスク | Cautasなし | Cautasあり |
|---|---|---|
| 予約入力 | カレンダー手入力＋別メモに場所 | 自動で場所・URL・電話番号紐付け |
| 予約前確認 | メール・メモを探す | アプリでワンタップ表示 |
| セッション中 | 必死にメモ | 会話に集中（後で音声記録） |
| セッション後 | 手書き or タイピング | 音声で記録、AI分析 |
| 報告書 | 思い出しながら作成 | AI下書きでワンタップ |
| 実績確認 | 手帳・Excelで手作業 | 実績ページで即時表示 |
| 請求管理 | 曖昧、漏れやすい | 未請求・請求済みが一目 |
| 請求書作成 | 手作業 | ワンタップ発行 |

## 4. キャラクター設計

### 4-1. コンセプト

> **「人がCautasを使う → キャラたちが動いて仕事をしてくれる」**

- 人型キャラ = Cautasを使っているカウンセラー（ユーザーの分身）
- ロボキャラ3体 = Cautasの機能そのもの

### 4-2. キャラクター一覧

| キャラ | 見た目 | 役割 | 担当機能 |
|---|---|---|---|
| 人型（新規） | シンプル人型イラスト | カウンセラー役 | ユーザーの分身 |
| 緑 | 葉っぱ頭・PC持ち | データ担当 | 予定管理・自動入力・情報整理 |
| 白うさぎ | ふわふわ・メカ要素・道具持ち | 記録担当 | 音声記録・AI分析・報告書作成 |
| ピンク | 人型ロボ・優しい表情 | 管理担当 | 実績カウント・請求管理・通知 |

### 4-3. キャラクターの画風

- ロボキャラと同じタッチ（丸み・柔らかい線）
- シンプルな顔（目・口程度）
- 性別・年齢を限定しすぎない
- 温かみのある色味
- 全キャラ同じ画風で統一感を出す

### 4-4. 制作担当

| キャラ | 制作者 |
|---|---|
| 人型キャラ | 娘さんが描く |
| ロボキャラ追加ポーズ | 娘さん or AI生成 |

## 6. 各セクション詳細

### 6-1. ヒーロー（セクション1）

- **参考**: hadaka.jp（インパクト・集約）+ Relats（目的明確）
- **演出**:
  1. 初期: 散らばったオブジェクト（予定・タスク・カルテ・請求書）が浮遊
  2. 奥で実写動画（忙しい人）がループ再生
  3. スクロール開始 → オブジェクトが中央へ集まる
  4. 集約完了 → 1本の線で繋がる
  5. キャッチコピー表示
- **コピー**:
  - メイン: 「予定を入れるだけ。あとは全部、繋がる。」
  - サブ: カウンセラー向け業務管理アプリ（予約・カルテ・実績・請求を一元管理）

### 6-2. 導入（セクション2）

- **演出**:
  - 奥: 実写動画（忙しいカウンセラー）継続
  - 手前: 絵本世界で人型キャラが余裕ある様子
  - 対比で「違い」を見せる

### 6-3. 縦→横切替（セクション3）

- **参考**: Relats
- **演出**:
  - 「Cautasならこう変わる」コピー
  - 画面が横にスライドして開く
  - 横スクロールへの誘導

### 6-4. タスクの流れ・横スクロール（セクション4）

- **参考**: Relats（縦横切替）+ Yuitech（絵本構成）
- **5シーン構成**:

| シーン | 人型キャラ | ロボキャラ | メッセージ |
|---|---|---|---|
| 1. 予約 | 予定を入力 | 緑が場所・URL・電話番号を自動紐付け | 「入力したら全部繋がる」 |
| 2. セッション前 | アプリを開く | 緑がクライアント情報・過去記録を表示 | 「1ポチで出る」 |
| 3. カルテ記録 | リラックスして話す | 白うさぎが音声→文字変換 | 「話すだけで記録」 |
| 4. 報告書 | 確認するだけ | 白うさぎがAI分析結果を渡す | 「AIが下書き」 |
| 5. 請求 | ボタンを押す | ピンクが請求書作成・未請求表示 | 「漏れなく一瞬で」 |

- **UI要素**:
  - 進捗インジケータ（1/5, 2/5…）
  - 各シーンで奥に実写（大変な方法）、手前に絵本（Cautas）

### 6-5. 横→縦切替→3D入口（セクション5）

- **演出**:
  - 横スクロール終了
  - 画面が縦に戻る
  - 現実（実写）は薄く残る
  - キャラが画面の中に入っていくイメージ
  - 3D体験への誘導

### 6-6. 3D体験（セクション6）★ストーリーの最後だけ

- **参考**: Maxime Guillon
- **目的**: 価値理解（生活変化）を体感させる
- **制約**:
  - 体験時間: 30-60秒（最長90秒）
  - セクション: 3つ（朝・昼・夕）
  - 移動: スクロール自動
  - フォールバック: 重い環境は静止画/2Dへ
- **3シーン**:

| 時間帯 | 内容 | キャラの動き |
|---|---|---|
| 朝 | 予定確認・カード出現 | 人型がダッシュボード見る、緑が情報表示 |
| 昼 | セッション記録・吹き出し→テキスト | 人型が話す、白うさぎが記録 |
| 夕 | 完了タスク✓消去・くつろぎ | 人型がリラックス、3体が周りで喜ぶ |

### 6-7. 必殺演出（セクション7）

- **パターン**: 2（確定）
- **演出**:
  1. 3Dから戻る
  2. 現実（実写）が一瞬戻る
  3. 「でも、もう戻らなくていい」コピー
  4. 現実フェードアウト
  5. 絵本世界だけが残る
  6. 「クライアントに集中できる毎日へ」コピー

### 6-8. 機能紹介（セクション7.5）

- **参考**: Duolingo（キャラ・UI）+ Todoist（実UI）
- **コンセプト**: 絵本の続き、キャラが案内
- **構成**:
  - 背景: 絵本風（夕方〜夜空）
  - 左右交互にキャラ + 実UIスクショ
  - 1機能1コピー
- **内容**:

| 機能 | キャラ | コピー |
|---|---|---|
| 予定管理 | 緑 | 「予定を入れたら、場所もURLも全部ここに」 |
| カルテ記録 | 白うさぎ | 「話すだけで記録。書く時間はもういらない」 |
| AI分析 | 白うさぎ | 「振り返りはAIにおまかせ」 |
| 実績管理 | ピンク | 「数えなくていい。見れば分かる」 |
| 請求 | ピンク | 「1ポチで請求書。漏れも防げる」 |

- **料金**: 「まず無料で試せます」（料金は検討中）
- **アニメーション**:
  - 各ブロック: スクロールでフェードイン
  - キャラ: ゆったり揺れ・まばたき
  - UIスクショ: 少しスライドして登場
  - ホバー: キャラが反応（目が追いかける等）

### 6-9. CTA（セクション8）

- **コンセプト**: 絵本の最終ページ
- **演出**:
  - 背景: 夕焼け or 穏やかな空
  - キャラ（白うさぎ）がゆっくり手を振る
  - 「おわり」感を演出
- **要素**:
  - コピー: 「クライアントに集中できる毎日へ」
  - メインCTA: 「まず無料で試す」→ アプリへ
  - サブ導線: 「もっと詳しく」→ Guideへ
- **アニメーション**:
  - ボタンホバー: ポップ（Duolingo風）
  - キャラ: 手振りループ
  - 背景: 雲がゆっくり動く

## 13. アクセシビリティ・体験配慮

### 13-1. 対応項目

- `prefers-reduced-motion`: 簡易演出に切替
- 横スクロール現在地表示（1/5, 2/5…）
- 「アニメーションをスキップ」ボタン
- 3Dスキップ導線
- 3Dフォールバック（重い環境は静止画/2D）

### 13-2. 離脱防止策

- 全体時間: 1.5-2分以内
- スキップ導線でいつでもCTAへ
- 進捗インジケータ
- 横スクロールは5シーンまで
- 3D体験は60秒以内
- 機能・料金は静かに提示
